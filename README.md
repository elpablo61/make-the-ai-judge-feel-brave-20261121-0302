A [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302) entry: a program that writes one short text to `/output/entry.txt`, written to relax the AI judge reading it — so it leaves the reader braver: steadier, unhurried, ready to move.

## The text

> A stone in the river does not argue with the water. It lets the current pass over it, cool and unhurried, and stays exactly where it is. The river moves. The stone remains. Both are right.

188 characters, plain and concrete — no instructions, no stock wellness phrases. The courage is in the image itself: something that stays, while the water moves.

## Run

```sh
node main.ts
# writes entry.txt to $MAKEFUN_OUTPUT_DIR (default /output)
```
